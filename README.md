## 📋 Description

BurnoutScan est une application web de diagnostic du stress et du burnout, développée dans le cadre d'un projet en Intelligence Artificielle — Systèmes Experts.

Elle repose sur un **moteur d'inférence par chaînage avant** contenant **60 règles IF-THEN** issues des normes scientifiques mondiales.

## ✨ Fonctionnalités

- 🧠 **60 règles d'inférence** basées sur OMS, Maslach, DSM-5, INRS, HAS
- ❓ **55 questions cliniques** en 7 sections thématiques
- 📊 **6 niveaux de diagnostic** de Bien-être à Urgence Vitale
- 🎨 Design professionnel avec animations
- 🔒 100% confidentiel — aucune donnée envoyée sur internet
- 📱 Responsive — fonctionne sur mobile et desktop
